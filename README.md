# Syeda Nahida Akter — research portfolio

A lightweight, accessible portfolio hosted with GitHub Pages.

## Updating content

- Edit publications, experience, and education in `js/data.js`.
- Edit page copy and section structure in `index.html`.
- Edit the visual system and responsive styles in `css/site.css`.
- Replace `files/Syeda_Nahida_Akter_CV.pdf` to update the CV without changing links.

No build step is required. Serve the repository with any static web server for local preview.
